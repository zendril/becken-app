What we’re working on

Added

  • A public version history for Becken.
  • Incline (hands on bench) and decline (feet on bench) push-ups in the Chest exercise group.
  • Create an exercise from search results with the searched name already filled in, even when other exercises match.
  • A debug preview of the flat push-up guide with four illustrated steps, readable captions and an enlarged view, available from the exercise library, picker, routine day editor and workout exercise cards.

Changed

  • App messaging emphasizes free use, no subscription and fully offline training; optional cloud transfers need a connection.

Fixed

  • Exercise search recognizes pushup, push-ups and push ups, including plural spellings.

0.6.5Development history

Workout progress that stays in view

Changed

  • A compact progress bar and completed/total count stay in the header while you scroll through sets.

0.6.4Development history

Record resistance sweeteners

Added

  • Choose eccentric, chains or inverse chains for each routine exercise, then record weight adjustments in each set.
  • Sweetener values carry forward from previous sets and are preserved in history and backups.

Changed

  • Unit conversion and deloading include sweetener adjustments; existing saved data migrates automatically.

0.6.3Development history

Keep your workout on screen

Added

  • An optional Settings toggle keeps the screen awake while Becken is in the foreground.
  • A dismissible tip introduces this setting after a few launches.

0.6.2Development history

Prepare private Play testing

Changed

  • Prepared the permanent Android app identity and release packaging for private Google Play testing.
  • Existing preview installations can transfer training data using manual backup and restore.

0.6.1Development history

  • A full-screen zoomable view of the routine → day → exercise → set → rep overview.

Fixed

  • Restored the original single-picture overview to the welcome tour.

0.6.0Development history

A welcome tour you can revisit

Added

  • A welcome tour explains routines, days, exercises, sets, reps, imports and backups.
  • Replay the tour anytime from Settings.

0.5.2Development history

Meet Momentum

Changed

  • Applied Becken’s Momentum branding to the launcher, startup screen, app header, Settings and light/dark palettes.

0.5.1Development history

Lift Log becomes Becken

Changed

  • Renamed the app to Becken and updated names for newly created backup files.
  • Existing training data and previously created Drive files keep their identities.

0.5.0Development history

Prepare optional Drive backups

Added

  • Implemented optional automatic Google Drive backups and account connection handling.

Changed

  • Backups use one readable file, including unfinished workouts; restore keeps cloud uploads off until reconnected.
  • Drive integration requires deployment setup and remains disabled in default builds. Live Google authorization and upload testing were not verified for this version.

0.4.0Development history

Versioned data and migrations

Added

  • Explicit schema versions for settings, exercise definitions, routines, workouts and editor drafts.

Changed

  • Older saved data and backups migrate to the new formats while retaining history and unfinished edits.
  • Unsupported or damaged data is rejected without resetting the existing database.

0.3.0Development history

A bigger, grouped exercise library

Added

  • An expanded catalog of 129 exercises grouped by muscle group.
  • Drill into a group or search the exercise library; custom exercises can be assigned a group.

0.2.1Development history

A cleaner deload dialog

Fixed

  • Fixed the deload dialog’s action layout when the reduction is set to 100%.

0.2.0Development history

Ease back in after a break

Added

  • An optional deload after a configurable break from training, with a reduction slider in 5% steps.
  • A debug-only setting can simulate a training break.

Changed

  • Tap weight and rep values to select them for replacement.

Fixed

  • Improved numeric input visibility when the keyboard opens.

0.1.0Development history

The first lifting log

Added

  • Create named routines and reusable training days with exercises, sets, weight and reps.
  • Use previous per-set results, pair exercises, substitute movements and edit workout history.
  • Save unfinished workouts locally, import routines and save or restore readable backup files.
