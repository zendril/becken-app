Workout import schema · release

Release follows the latest shipped Play build, currently 0.7.4. Becken is in private Internal testing; this does not announce public availability.

This file creates a reusable routine using liftlog.routine, schema 3. It imports into Becken 0.7.0 and later versions supporting this schema.

Read or download the JSON Schema · Download example workout · Create a workout with AI

Import with Routines → Import, then review the preview. Import creates a new routine; it does not replace an existing routine or restore a backup.

File structure

Supply exercise definitions in exercises, and a named routine with its weight unit and ordered days. Each day's entries reference an exercise ID. Use the exact format, version and fields in the linked schema.

Exercise entries

FieldSchema rule
exerciseId{"$ref": "#/$defs/id"}
setCount{"type": "integer", "minimum": 1, "maximum": 50, "default": 3}
startingWeight{"type": ["number", "null"], "minimum": 0, "maximum": 100000}
startingReps{"type": ["integer", "null"], "minimum": 1, "maximum": 10000}
pairId{"anyOf": [{"$ref": "#/$defs/id"}, {"type": "null"}]}
sweeteners{"type": "array", "items": {"enum": ["ECCENTRIC", "CHAINS", "INVERSE_CHAINS"]}, "uniqueItems": true, "maxItems": 2, "not": {"allOf": [{"contains": {"const": "CHAINS"}}, {"contains": {"const": "INVERSE_CHAINS"}}]}, "default": []}
measurementType{"enum": ["REPS", "TIME", "DISTANCE"], "default": "REPS"}
distanceUnit{"enum": ["FT", "M", null]}
startingSeconds{"type": ["integer", "null"], "minimum": 1, "maximum": 86400}
startingDistance{"type": ["number", "null"], "exclusiveMinimum": 0}

Units and import rules

Starting weights use the routine's lb or kg unit. Dumbbells use perHand: true for weight in each hand or false for combined weight. Bodyweight entries record added weight, with 0 for unweighted. Starting values are suggestions and never count as completed work.

Files must be UTF-8 JSON under 2 MiB, with unique IDs, valid exercise references, no repeated exercise within a day, and exactly two entries for each non-null pair ID. The schema describes structure; Becken additionally checks references and pairs. Unknown fields and unsupported versions are rejected.

Example

These quantities demonstrate the file format; adapt the routine to your own goals and experience.

{
  "format": "liftlog.routine",
  "version": 3,
  "exercises": [
    {
      "id": "squat",
      "name": "Barbell squat",
      "equipment": "BARBELL",
      "perHand": true,
      "group": "LEGS",
      "defaultMeasurementType": "REPS"
    },
    {
      "id": "two",
      "name": "Farmer's carry (two-handed)",
      "equipment": "DUMBBELL",
      "perHand": false,
      "group": "FULL_BODY",
      "defaultMeasurementType": "DISTANCE"
    },
    {
      "id": "one",
      "name": "Farmer's carry (one-handed)",
      "equipment": "DUMBBELL",
      "perHand": true,
      "group": "FULL_BODY",
      "defaultMeasurementType": "DISTANCE"
    }
  ],
  "routine": {
    "name": "Example: strength and carries",
    "unit": "LB",
    "days": [
      {
        "name": "Strength and distance",
        "exercises": [
          {
            "exerciseId": "squat",
            "setCount": 3,
            "measurementType": "REPS",
            "startingWeight": 45,
            "startingReps": 8
          },
          {
            "exerciseId": "two",
            "setCount": 2,
            "measurementType": "DISTANCE",
            "distanceUnit": "FT",
            "startingWeight": 80,
            "startingDistance": 100
          },
          {
            "exerciseId": "one",
            "setCount": 4,
            "measurementType": "DISTANCE",
            "distanceUnit": "M",
            "startingWeight": 40,
            "startingDistance": 20
          }
        ]
      },
      {
        "name": "Timed carries",
        "exercises": [
          {
            "exerciseId": "two",
            "setCount": 2,
            "measurementType": "TIME",
            "startingWeight": 80,
            "startingSeconds": 30
          },
          {
            "exerciseId": "one",
            "setCount": 4,
            "measurementType": "TIME",
            "startingWeight": 40,
            "startingSeconds": 30
          }
        ]
      }
    ]
  }
}
