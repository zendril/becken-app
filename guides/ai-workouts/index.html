Create a workout with AI

Describe the training you want. Turn it into a routine you can import into Becken.

You can use Gemini, ChatGPT or Claude to help write the file. The same prompt works with any assistant that can produce JSON. Becken does not connect to an AI account, and this page does not collect your answers.

1. Describe what works for you

Start with your goals and experience. Tell the AI what equipment you have, which movements to avoid or modify, how often you want to train, how long each session should be, and how hard you want to work. Include recovery days and exercise preferences. These details shape the routine; they are not extra fields to add to the import file.

2. Give the AI the format

Use the current release schema and example. Check its compatible app version against the version in Becken Settings. Update Becken or choose an older published schema if needed.

Copy this prompt into your preferred assistant and replace the bracketed details. If it cannot open the links, download and attach the schema and the example. Keep the requested file within the schema's supported features.

Help me create a workout routine that I can import into Becken.

My goals: [strength, muscle growth, general fitness, or another goal]
My training experience: [beginner, returning, experienced]
Available equipment: [list what I can use]
Movements to avoid or modify: [list restrictions and preferred alternatives]
Schedule: [days per week and minutes per session]
Desired intensity: [easy, moderate, challenging; include recovery preferences]
Weight units: [lb or kg]
Exercise preferences: [include carries, timed holds, or other preferences]

Use the current Becken import schema:
https://becken.app/schemas/workout/release/schema.json
Use this valid example as a format reference:
https://becken.app/schemas/workout/release/example.json
Compatibility information:
https://becken.app/schemas/workout/release/

If you cannot read these URLs, ask me to attach the schema and example.
Ask any necessary clarifying questions before suggesting a routine. Explain
how the proposed routine fits my goals, schedule and desired intensity.
Once we agree, create a UTF-8 .json file that follows that schema exactly.
Use its exact format and version. Include only fields supported by the schema.
Keep exercise IDs unique and references valid. Importable routines are not backups.
Use starting values only as optional suggestions. Distinguish combined dumbbell
weight from weight per hand. Use exactly one measurement for each exercise entry,
and only use time or distance when supported by the linked schema.
For a one-handed carry, describe one side per set and include sets for both sides.
Validate the JSON against the schema if you have a validation tool available;
otherwise say that you have not run a validator. Do not claim validation you did not run.
Return the final file, or its JSON content alone without Markdown code fences.

3. Review and save the file

Review the proposed exercises, schedule, intensity and starting suggestions. AI output can contain mistakes; adjust anything that does not fit your goals or restrictions. Then ask for the final file.

Download it as my-workout.json. If the assistant only provides text, copy the JSON into a plain-text editor and save it as UTF-8 with the .json extension. Leave out chat explanations and Markdown fences.

4. Import into Becken

  1. Open Routines → Import.
  2. Select your JSON file.
  3. Review the routine name, units, days and exercises in the preview.
  4. Choose Import routine, then open the routine to review its starting suggestions.

Import adds a new routine. Starting suggestions are not completed workout results. A full backup uses a different format and belongs in Settings, not routine import.

If import reports an error

Copy the error message back to the AI together with the same schema and ask it to repair the file. Check that the file contains JSON only, uses a supported schema version, and is under 2 MiB. Unsupported fields, missing exercise references, duplicate exercises within a day and incomplete pairs can prevent import.

Try the downloadable example to check the import steps. Its quantities illustrate the format and are not a personalized training prescription.
